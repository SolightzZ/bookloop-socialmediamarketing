# เสิร์ฟ frontend จากโดเมนเดียวกับ backend (same-origin) — ทางเดียวที่ auth
# ใช้งานได้จริงบน InfinityFree free (เลิกพึ่ง GitHub Pages ข้าม origin ซึ่งโดน
# edge challenge ?i=1 + third-party cookie block ทุกครั้ง แก้ด้วยโค้ดไม่ได้)

## ขั้น 1: build ในเครื่อง (PowerShell ที่ root ของ repo)
#  PARSE: base /app/ + API ชี้โดเมนเดียวกัน (absolute URL แต่ same-origin = ไม่เกิด CORS)
npm run build:app
#  ได้โฟลเดอร์ dist/ (index.html + assets/)

## ขั้น 2: อัปโหลดผ่าน InfinityFree File Manager (หรือ FTP)
#  - สร้างโฟลเดอร์ htdocs/app/
#  - อัปโหลด "เนื้อข้างใน dist/" ทั้งหมดเข้า htdocs/app/
#    (ต้องได้ htdocs/app/index.html, htdocs/app/assets/... )
#  - อัปโหลดไฟล์ app.htaccess (ไฟล์ข้างๆ เอกสารนี้) เป็น htdocs/app/.htaccess
#    (File Manager อาจซ่อนไฟล์ dotfile — อัปโหลดแล้วเช็กว่า .htaccess อยู่ใน htdocs/app/)
#  - ห้ามทับ htdocs/index.php / htdocs/api/ (backend เดิมต้องอยู่ครบ)

## ขั้น 3: อัปโหลด backend ที่แก้แล้ว (ถ้ายังไม่เคย — รอบเดียวจบ)
#  frontend ใหม่ส่ง text/plain + token ใน query/body จึงต้องใช้ backend ใหม่:
#    Services/Http.php (อ่าน JSON ไม่พึ่ง Content-Type + รับ token จาก query/body)
#    api/index.php (Allow-Credentials)
#    api/auth_delete_account.php + api/newsletter_status.php (รับ POST + _method=DELETE)
#  + เช็ก htdocs/.env ว่ามี ALLOWED_ORIGIN=https://panitijahem.xo.je
#    (same-origin ส่ง Origin: https://panitijahem.xo.je — ต้องอยู่ใน allow-list)

## ขั้น 4: ทดสอบ
#  1. เปิด https://panitijahem.xo.je/app/ ตรงๆ ครั้งแรก (รับ cookie __test แบบ first-party)
#  2. กดสมัครสมาชิกในหน้านั้น — request เป็น same-origin ไม่ติด CORS อีก
#  3. ถ้ายังพลาด: เปิด DevTools → Network → ดู response ของ auth_register.php
#     - ได้ JSON (แม้ success:false) = ถึง PHP แล้ว เหลือแค่ validation/ข้อมูลฟอร์ม
#     - ได้ HTML aes.js = cookie หมดอายุ (ทุก ~6 ชม.) กลับไปทำข้อ 1 ใหม่

## หมายเหตุ
#  - GitHub Pages (solightzz.github.io/...) เก็บไว้เป็นหน้าดูได้อย่างเดียว auth จะใช้
#    ได้เฉพาะโหมดออฟไลน์ (บัญชีบนเครื่อง) จนกว่าจะย้าย backend ออกจาก InfinityFree free
#  - อย่าเอา dist/ หรือ .htaccess ที่มี path จริง commit ปนกับไฟล์นี้ (ไฟล์นี้ไม่มี secret)
